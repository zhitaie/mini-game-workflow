# ski-endless

第一款真实接入的小游戏。

当前定位：

- 使用 `Cocos Creator` 作为客户端引擎
- 首版只做单人滑雪无尽模式
- 后续允许扩展地图和模式，但当前不提前做成复杂平台模块

当前阶段目标：

- 建立稳定的 Cocos 项目目录
- 验证现有平台 runtime 能否被真实游戏接入
- 让后续玩法开发在独立 app 中进行，不再挤在 `game-sample`

当前预留的扩展方向：

- 地图主题：`snowfield`、`forest`、`night`
- 模式：`endless`、`time_attack`、`challenge`

这些扩展当前先留在游戏内容层，不要求平台层先做额外抽象。
